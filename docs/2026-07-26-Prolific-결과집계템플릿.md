# Prolific 첫인상 테스트 — 결과 집계 템플릿

- 대상: NEON FLEET 해외 15명·$1 첫인상 테스트
- 기준 작업지시서 §9.3
- 데이터 출처: GA4 이벤트 `playtest_started · playtest_limit_reached · playtest_feedback_submitted · playtest_completed`
- 원칙: 개인정보·자유서술·Prolific PID는 수집하지 않으므로, 아래는 익명 집계값만 채운다.

> 사용법: 파일럿(3명)과 본 테스트(12명)를 코호트(`playtest_cohort`)로 나눠 각각 채우고, 마지막에 합산 15명 관점을 본다. 표의 숫자는 실제 데이터로 대체.

### 부록: GA4에서 값 뽑는 요령

- 탐색(Exploration)에서 이벤트명으로 필터 후, 매개변수(`fun_rating`·`clarity_rating`·`replay_intent`·`peak_moment`·`friction_area`·`end_reason`·`elapsed_sec`·`playtest_cohort`·`completion_method`)를 측정기준/측정항목으로 사용.
- 코호트 구분은 `playtest_cohort`(pilot/main/unknown). unknown은 URL의 `utm_content`가 pilot/main이 아닐 때이므로, 진입 링크가 규격대로면 거의 나오지 않아야 한다.
- Prolific PID·완료 코드·전체 URL은 이벤트에 없음(설계상 전송 금지) — 개인 단위 재식별은 불가하며, 익명 분포로만 해석한다.
