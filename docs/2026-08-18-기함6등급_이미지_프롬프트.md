## 0. 왜 지금 것이 "덩치만 커지는" 느낌인가 (실측)

만들기 전에 원인을 알아야 같은 결과가 안 나옵니다.

### 원인 ① T0·T1이 **아군 호위기와 같은 모델**이다

| 등급 | 현재 모델 | 정체 |
|---|---|---|
| T0 EMBER | `a1_model.glb` | ⚠️**드론과 같은 파일** (60기가 주위에 떠다님) |
| T1 FLARE | `a2_model.glb` | ⚠️**순양함과 같은 파일** |
| T3 AURORA | `a0_model.glb` | 아군 원화 계열 |
| T2·T4·T5 | `t2·t4·t5` | 별도 출처 |

초반 기함이 **주변 호위기와 똑같이 생겼습니다.** 특별해 보일 수가 없습니다.

### 원인 ② 파이프라인이 **비율을 지운다**

`js/chase3d-glb.js`
```js
const k = 1 / (Math.max(size.x, size.y, size.z) || 1);   // 가장 긴 축을 1로
```

모든 기함이 **가장 긴 축을 1로 눌러** 정규화된 뒤, 등급 배율만 붙습니다.

```
등급 배율  [0.62, 0.75, 0.88, 1.00, 1.13, 1.26]   ← T0→T5 가 겨우 2.03배
```

⚠️**이걸 안 고치면 새 모델을 만들어도 똑같이 납작해집니다.** 날렵한 정찰기와 넓적한 항모를
만들어도 둘 다 같은 길이로 눌립니다. → **파이프라인 수정은 제(클로드) 몫**이며, 이 문서와 함께 진행합니다.
