## 4. 배율·전환 계약 (§3.1)

```text
DEFAULT 1.00 · MIN 1.00 · MAX 2.20 · STEP 0.10
CHASE_START_ZOOM 1.60 · CHASE_FULL_ZOOM 2.00
chaseBlend = smoothstep(1.60, 2.00, zoom)   (경계에서 기울기 0 → 점프 최소)
```

| 목표 배율 | 화면 | chaseBlend(실측) |
|---:|---|---:|
| 100~150% | 기존 전술 확대 | 0 |
| 160% | 전환 시작(아직 전술) | **0** |
| 180% | 전술·추적 연속 보간 | **0.5** |
| 200% | 완전 추적 | **1** |
| 220% | 완전 추적 + 추가 근접 | **1** |

chaseBlend는 줌과 **별도 ease-out**(τ≈120ms → ~360~420ms)으로 보간해 카메라가 부드럽게 굽는다. reduced-motion이면 즉시 전환. 처음 완전 진입 시 `함미 추적 시점 / Pursuit View` 850ms 안내.

## 5. 투영 수학과 상수 (§4.2)

모든 상수를 `PROJECTION` 한 객체에서 관리(하드코딩 없음, 화면 비율 기반 → 해상도 독립):

```text
horizonYFrac 0.20 · nearYFrac 0.83
farLateral 0.38 · nearLateral 1.25
farObjScale 0.42 · nearObjScale 1.50
depthPow 1.35
```

- 깊이: `depth = clamp((worldY - 0) / (squadY - 0), 0, 1)` — 0 소실점, 1 기함.
- 각 점: 전술 A = `squad + (p-squad)*zoom`, 추적 B = 원근 투영, **최종 = lerp(A, B, chaseBlend)** (위치·표시크기 모두).
- 근거리 affine(입력 역변환용): `screenX = C0 + (worldX-squadX)*slope`, `C0 = lerp(squadX, centerX, blend)`, `slope = zoom*lerp(1, nearLateral, blend)`.
- **100%(blend=0)은 전술과 완전 동일** → 기존 렌더와 픽셀 차이 0. **160% 전환 시작(blend=0)도 전술과 연속** → 경계 점프 ≤1px(테스트 CH-09, 실측 0px).

## 6. 렌더 경로 (§5)

- `chaseBlend ≤ 0.001`: **기존 전술 경로**(global translate/scale + 기존 draw 순서 + effects.drawWorld) 그대로 → 100~160% 재작성 없음, 픽셀 동일.
- `chaseBlend > 0.001`: **개체별 투영**(`drawProjected`가 개체 중심을 투영해 translate/scale, save/restore 개체당 균형). 투영 대상: 함선·드론·순양함·캠페인 편대·적·정예·보스·플레이어탄·적탄·아이템·게이트·파티클·링·섬광·데미지텍스트.
- **화면 고정(투영 안 함)**: HUD·전체 화면 플래시(`effects.drawScreen`는 분기 밖 공통)·컷신·시네마 띠·DOM 오버레이·pause/charge 버튼·안내 문구. (테스트 CW2-19: drawScreen 분기 밖 1회.)
