## 1. 한 줄 요약

드론 편대를 좌우로 움직여 크리스탈·수송선을 부수며 편대를 불리고, 워프 게이트의 `+ × − ÷` 로
편대 수가 늘거나 줄고, 트랙 끝의 보스를 잡는 **무료 브라우저 슈팅**.
확대하면 **실제 3D 함미 시점**으로 전환되지만 게임 판정은 계속 2D 다.

- 광고 없음 · 과금 없음 · 설치 없음 · 계정 없음
- 순수 JavaScript + Canvas 2D (빌드 도구 없음). 3D 는 Three.js, **확대할 때만 지연 로드**

### 테스트의 성격

단순히 개수만 많은 게 아니라, 이번 회차에 **문자열 대조를 실행 기반으로 바꿨다.**
"코드에 이 글자가 있다"가 아니라 **실제 함수를 돌려 결과를 잰다.**

그리고 수정마다 **고의로 망가뜨려 실패를 확인**했다(mutation). 이번 회차 실적:

| 대상 | 고의 회귀 | 결과 |
|---|---|---|
| 랜스·메아리·시즈 피격 기록 | 배선 제거 | 6건 실패 ✅ |
| 입자 상한 RNG 보존 | `continue`→`break` | 3건 실패 ✅ |
| 고우선 예약 | `priority:'high'` 제거 | 3건 실패 ✅ |
| 색 장애 복구 | 복구 코드 제거 | 부분 적용 증상 재현 ✅ |
| 보조무기 좌우 | "항상 오른쪽" 복원 | 3건 실패 ✅ |
| 분사구 대칭 | 마운트 비대칭화 | 2건 실패 ✅ |
| 효과음 선로딩 | 목록에서 제거 | 2건 실패 ✅ |

⚠️"통과했다"와 "잡을 수 있다"는 다르다. 위는 **잡을 수 있다**를 확인한 기록이다.

## 4. 최근 회차에 고친 것 (§G-39 ~ §G-44)

| 회차 | 내용 | 계기 |
|---|---|---|
| §G-39 | 3D 에서 적 체력·피격이 **아무 표시도 없던 것** 해결. 발칸·레이저 피탄 반응 신설 | 이사님 제보 |
| §G-40 | 차지빔 폭: **판정 = 2D 그림 = 3D 그림** 한 값으로 통일 | 이사님 제보 |
| §G-41 | 출격 직후 레이저가 폴백 도형으로 나오던 문제 (선로딩 누락) | 이사님 제보 |
| §G-42 | 보조무기·공명 레일이 **늘 오른쪽에서만** 나가던 문제 → 좌우 교대 | 이사님 제보 |
| §G-43 | 코인 밝기 23%→42% · **함미모드 추진 제트 신설**(3D 에 아예 없었다) | 이사님 제보 |
| §G-44 | 효과음 48개 전면 교체 (무료등급 → CC0 → **ElevenLabs 유료**) | 이사님 제보 |

⚠️**전부 이사님이 실기에서 발견한 것들이다.** 자동 테스트로는 안 잡히는 종류였다 —
"보이지 않는다", "소리가 약하다", "한쪽으로 쏠린다" 는 사람이 봐야 안다.
**이것이 커뮤니티 피드백이 필요한 이유이기도 하다.**

## 5. 게임 규칙을 바꾼 것 (승인 이력)

⚠️표시·연출이 아니라 **실제 판정**이 바뀐 항목. 전부 이사님 승인 아래 진행했다.

| 항목 | 이전 | 현재 | 영향 |
|---|---|---|---|
| 차지빔 판정 폭 | `widthShipMult 1.05` | **1.40** + `hitWidthMult 1.2` | 판정 폭 1.33배 확대 |
| 보조무기 하드포인트 | `+22` 고정 | **±22 교대** | 탄도 분포가 좌우로 갈라짐 |
| 사망 타격 플래시 | 있음 | **없음** (사망 폭발이 담당) | 화면 변화 + RNG 안정 |

⚠️**"밸런스 무변경" 이라고 쓰면 안 된다.** 피해량·발사율·탄 수·관통은 그대로지만
**탄이 실제로 존재하는 자리**가 바뀌었다. 개별 교전은 이전과 동일하지 않다.

### 6-1. 실플레이 검증의 공백

자동 테스트 1,107개는 **부품이 규칙대로 동작하는지**를 보증하지, **재미있는지·쾌적한지**를 보증하지 않는다.

### 6-2. 알려진 제한 (보류 판정)

| 항목 | 증상 | 상태 |
|---|---|---|
| `Blinker`·광폭화 `Boss` 피격 플래시 | 강도가 무시돼 **항상 최대 밝기**. 감쇠가 안 보인다 | 이사님 "괜찮다" 판단 |

## 8. 등록 전에 판단하실 것

### 반드시 확인이 필요한 것

1. **모바일 실기기에서 한 판** — 터치 조작이 되는가, 프레임이 버티는가
2. **첫 60초** — 처음 하는 사람이 뭘 할지 아는가 (정적 안내 1회뿐, 단계형 학습 없음)

~~첫 로딩 시간~~ — **8/14 실측으로 해소.** 6.48MB / 0.51초.
느린 회선 환산으로도 4G(20Mbps) 약 2.6초, 3G(3Mbps) 약 17초다. 병목이 아니다.

### 지금 없는 것

- **게시용** 스크린샷·GIF — 개발·QA 캡처는 다수 있으나, 구도·해상도·문구를 정리한 대표 4~5장과 10초 GIF 는 미제작
- ⚠️**단계형** 튜토리얼 — 첫 출격 전 **1회성 정적 안내는 있다**(`js/ui.js:179`). 플레이 중 행동으로 배우는 단계 학습과 이해도 검증이 없다
- 피드백 받을 창구 (게임 안에 링크가 없다)

### 규모 관련 — ⚠️실측하니 문제가 아니었다

**공개 사이트를 실제로 열어 브라우저가 받아 가는 바이트를 쟀다**(2026-08-14, Chromium
Resource Timing `encodedBodySize`, 고유 URL 122개 기준).

| 시점 | 실제 다운로드 | 요청 수 | load 완료 |
|---|---:|---:|---:|
| **타이틀 화면까지** | **6.48 MB** | 122 | 0.51 초 |
| **출격해서 플레이까지** | **7.56 MB** | 171 | — |

내려받는 것의 정체:

| 형식 | 개수 | 용량 | 비고 |
|---|---:|---:|---|
| webp 아트 | 57 | 4.58 MB | 가장 큰 5개가 전부 VFX(보스 장갑파괴 374KB 등) |
| **폰트 woff2** | 2 | **1.48 MB** | ⚠️**단일 파일 1·2위**(773KB·748KB). Pretendard 전체 자소 |
| OGG 사운드 | 49 | 1.08 MB | 효과음 48 + 타이틀 BGM 574KB |
| JS 코드 | 61 | 0.36 MB | 압축 후 |

**GLB(3D 모델) 요청 0건, 나머지 BGM 20곡 요청 0건.** 3D는 200% 이상 확대할 때만,
BGM은 해당 구간에 들어갈 때만 받는다 — **지연 로드가 이미 되어 있다.**

⚠️**따라서 "49.5MB" 는 플레이어가 겪는 값이 아니다.** 그 숫자는
`dist/crazygames-basic/` — CrazyGames 제출용으로 **모든 자산을 미리 묶은 패키지**의 총량이다.
(참고로 이 패키지 안의 구성은 `assets/3d` 18.67MB 37.7% · `assets/sound` 17.06MB 34.5% ·
`assets/art2-webp` 7.37MB 14.9% · 나머지 6.42MB.)

⚠️**이전 판의 "BGM 이 46MB, 93%" 도 제 측정 오류였다.** 원본 폴더(`assets/sound` 46.6MB,
MP3 29.5 + OGG 17.1)를 배포물 총량과 비교해 버렸다. 배포물에는 **MP3 가 0개**다.

**결론 — 초기 다운로드 감축은 지금 할 일이 아니다.**
6.5MB / 0.5초는 브라우저 게임으로 넉넉히 빠른 축이다. "20MB 미만으로 줄이자" 는 과제는
**이미 충족돼 있다.** 굳이 더 줄인다면 순서는 **폰트 자소 축약(1.48MB → 200KB 대, 최대 감축폭)**
→ VFX webp 해상도 조정이며, **3D 모델·오디오는 대상이 아니다**(애초에 안 받는다).

## 9. 평가 요청 시 물어볼 것 (제안)

커뮤니티에 올릴 때 이 4가지를 물으면 가장 쓸모 있는 답이 온다.

1. **첫 60초** — 뭘 해야 할지 알겠는가? 어디서 막혔는가?
2. **편대 성장** — 보람 있는가, 아니면 노가다인가?
3. **3D 함미 시점** — 도움이 되는가, 어지러운가?
4. **난이도** — 어디서 죽었고, 공정하다고 느꼈는가?

⚠️피드백 처리 원칙: **한 명의 의견으로 게임을 바꾸지 않는다.**
같은 지적이 3명 이상에게서 나올 때만 신호로 본다. 단 **버그는 1명이라도 즉시**.
