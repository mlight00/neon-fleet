## 0. 이 문서만 보고 만들 수 있게

만드시는 분은 **§4 표 하나만** 보시면 됩니다. 파일명·개수·길이·느낌이 전부 거기 있습니다.
§1~§3 은 규격, §5 는 만들 수 있는 곳, §6 은 완성 후 저에게 주시는 방법입니다.

## 1. 파일 규격 (현재 파일 실측값 — 그대로 맞추면 코드 수정 0)

| 항목 | 값 |
|---|---|
| **형식** | **OGG Vorbis** (`.ogg`) — 필수 |
| 샘플레이트 | 48,000 Hz 권장 (44,100 도 무방) |
| 채널 | **모노** 권장 (게임이 위치감을 따로 입힌다) |
| 비트레이트 | 80~128 kbps |
| 최대 길이 | **2.0초** (그보다 길면 게임이 잘라 쓰지 않고 그냥 길게 난다) |
| 앞 여백 | **0초** — 파일 맨 앞부터 소리가 나야 한다 |
| 최고 음량 | −1 dBFS 이하 (클리핑 금지) |

⚠️**형식이 OGG 가 아니면 게임이 못 읽습니다.** WAV·MP3 로 만드셨으면 §6-2 방법으로 변환하거나
그냥 원본을 주시면 제가 변환하겠습니다.

⚠️**앞 여백이 있으면 발사 소리가 늦게 납니다.** 총 쏘는 순간과 소리가 어긋나 보입니다.

---

## 2. 파일명 규칙 — 반드시 지켜야 함

```text
nf_sfx_<종류>_<번호>.ogg
```

- `<종류>` = §4 표의 **id** 를 그대로. 오타 하나면 그 소리가 안 납니다
- `<번호>` = 1 부터 시작하는 연번. 같은 종류의 변형입니다
- 예: `nf_sfx_vulcan_1.ogg`, `nf_sfx_vulcan_2.ogg`, `nf_sfx_vulcan_3.ogg`

**변형(번호)이 여러 개인 이유**: 발칸처럼 초당 여러 번 나는 소리는 같은 파일만 반복하면
기계처럼 들립니다. 게임이 매번 다른 변형을 골라 씁니다.
→ 변형끼리는 **같은 소리의 미묘한 차이**여야 합니다. 완전히 다른 소리면 안 됩니다.

## 3. 전체 톤

**네온 사이버 아케이드 슈팅.** 어두운 우주 배경에 청록·자홍 네온이 번쩍이는 화면입니다.

- 무기는 **묵직하고 단단하게** — 얇고 삑삑거리는 레트로 8비트 소리는 화면과 안 맞습니다
- 폭발은 **저역이 받쳐주는 쿵** — 고역 노이즈만 있으면 종이 구기는 소리가 됩니다
- UI 는 **짧고 깔끔하게** — 존재감이 크면 반복될 때 피곤합니다
- 전체적으로 **전자음 계열**. 현실 총기·폭죽 녹음보다 신시사이저·에너지 무기 쪽

## 6. 완성 후

### 6-1. 그대로 주셔도 됩니다

파일명·형식이 안 맞아도 됩니다. **원본 그대로 주시면 제가 맞춥니다.**
다만 어느 파일이 §4 표의 어느 `id` 인지는 알려 주셔야 합니다.

폴더에 넣어 주실 위치:

```text
E:\workspace\claude\neon-fleet\worktrees\stage1-analytics\assets\sound\_new-sfx\
```

### 6-2. 직접 변환하실 경우

ffmpeg 이 이 PC 에 설치돼 있습니다. 폴더 안 모든 WAV/MP3 를 규격에 맞는 OGG 로 바꿉니다.

```bash
for f in *.wav; do ffmpeg -i "$f" -ac 1 -ar 48000 -c:a libvorbis -b:a 96k "${f%.wav}.ogg"; done
```

### 6-3. 함께 적어 주실 것 (라이선스 근거)

나중에 상업 배포를 정하실 때 필요합니다. 메모 한 장이면 됩니다.

```text
출처      : (예) ElevenLabs / Kenney Sci-Fi Sounds / jsfxr
요금제    : (예) Creator 월 구독 / 무료 CC0 / 해당 없음
생성·다운로드일 : 2026-08-__
라이선스  : (예) 상업 이용 가능 / CC0 / 요금제 약관 v__
```

## 7. 제가 할 일 (파일 받은 뒤)

1. 형식·길이·앞 여백·음량 검사 → 규격 밖이면 변환
2. `assets/sound/` 에 배치, 기존 48개는 백업 폴더로 이동
3. 게임에서 23종 전부 실제로 재생되는지 자동 확인
4. 라이선스 감사 문서(`docs/release/.../asset-license-audit.md`) 갱신 — **UNKNOWN → 확인됨**
5. 크레딧 표기 추가, 빌드·테스트·배포

⚠️**코드 수정은 없습니다.** 파일명만 맞으면 그대로 물립니다.
