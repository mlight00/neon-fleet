# NEON FLEET P0 리텐션 — 브라우저 QA 증거 (2026-07-26)

- 검증 방식: 로컬 dev 서버(`python -m http.server 8321`)에서 실제 게임 모듈을 로드하고,
  실제 사용자 동선(버튼 클릭·탭·키보드·사망)을 발생시킨 뒤 **살아있는 게임 상태(`window.__NF`)와
  `localStorage`, 오버레이 DOM**을 계측했다. 각 항목은 실측값이다.
- 스크린샷 한계: 이 게임은 `requestAnimationFrame` 캔버스이고 QA 브라우저 탭이 `document.hidden`
  상태라 rAF가 멈춰 이미지 캡처(computer screenshot)가 타임아웃된다. 대신 DOM·상태 계측으로
  동일 사실을 증명한다. 헤드리스 전진은 `__NF.step(frames)`로 수행.
- 데스크톱 기준 1280×720. 모바일 항로는 PointerEvent(pointerType:'touch')로 터치를 재현.
