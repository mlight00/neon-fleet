## 3. 성능 — 저사양 프로파일

**시나리오**: 적 42기(6종 × 7) · 240 프레임 × 5회 반복 · 기함 tier3 · 삼각형 579,847 · draw call 8

| | 프레임당 평균 |
|---|---|
| 색 갱신 없음 | 0.536 ms (5회: 0.522 / 0.558 / 0.484 / 0.607 / 0.510) |
| 색 갱신 있음 | 0.485 ms (5회: 0.487 / 0.494 / 0.482 / 0.491 / 0.473) |
| **잡음 폭** | **0.134 ms** |

색 갱신이 있는 쪽이 **오히려 빨랐다** — 즉 차이가 잡음보다 작다. **비용은 측정 한계 아래**다.

순수 색 계산만 따로 재면 42개 × 240 프레임에 **프레임당 0.0058 ms**(5.8 µs)다.
0.5 ms 프레임과 0.134 ms 잡음에 대해 사실상 보이지 않는다.

⚠️이 값은 **렌더 + 색 갱신** 비용이다. 2D Canvas 합성 비용은 여기에 없다(§5 참조).

## 6. 알려진 제한 (이사님 실기 승인)

`Blinker`(`js/entities.js:3864`)와 광폭화 `Boss`(`js/bosses.js:397`)는 몸체 blit **직전에**
`ctx.globalAlpha` 를 절대값으로 덮어써, 계산한 플래시 강도가 그 순간 사라진다.

실측: 의도 알파 Blinker 0.051 / Boss 0.106 → 실제 1.0. **항상 최대 밝기이고 감쇠가 보이지 않는다.**

⚠️**이 두 클래스에서는 reduced-motion 설정도 무시된다.** 접근성이 보장된다고 쓰면 안 된다.
근본 해결은 그 클래스들이 `*=`(상대곱)를 쓰는 것 — 별도 태스크. 이사님이 "괜찮다"로 판단해 보류 중이다.
