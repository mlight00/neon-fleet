### 지적 사항

- **P2 개선 — 개발용 BossLab 사망이 무료 개조를 소모함**  
  `js/main.js:1948`, `js/main.js:2056`  
  BossLab은 `r.bossLab`으로 표시되지만, 플레이어 사망 시 일반 `endExpedition('death')`로 진입합니다. 무료 지급 조건이 `reason === 'death'`만 확인하므로 BossLab 사망에서도 영구 강화와 `firstDefeatUpgrade`가 저장되어 실제 캠페인의 첫 사망 혜택을 소모합니다. `!r.bossLab` 또는 일반 원정 여부를 함께 확인해야 합니다.

- **P3 사소 — 첫 안내를 본 저장에서는 직접 진입형 개발 모드가 첫 노드를 두 번 초기화함**  
  `js/main.js:236`, `js/main.js:481`, `js/main.js:552`, `js/main.js:917`  
  `firstGuideSeen=true`이면 `newExpedition()` 내부에서 루트가 자동 진입됩니다. 이후 BossLab/CoreLoop/Campaign25 시작 함수가 다시 `enterNode(root)`를 호출합니다. 최종 상태는 두 번째 호출로 덮이지만, 청크 RNG를 두 번 소비하고 시작 효과·사운드를 중복 생성하며 개발 측정 결과가 저장 상태에 따라 달라질 수 있습니다. 직접 진입형 부트스트랩에서는 자동 루트 진입을 억제할 필요가 있습니다.

그 외 요청한 중복 지급 방어, `r.settled` 정산 1회, 지도 `confirmed` 가드, 섹터·노드 자동 진입 조건, 타이틀 상태 초기화에서는 추가적인 actionable regression을 찾지 못했습니다. 전체 테스트는 **509개 모두 통과**했습니다.
