## 3. 조치 — 실모델을 게임 시점으로 렌더해 2D 스프라이트로

1. **각도 결정** — 8종을 정면·25°·45° 세 각도로 렌더해 대조판을 만들고 개체별로 골랐습니다.
   코인·파워는 정면(원·별 대칭), 돌격기는 30°(돌진 쐐기가 살아남), 크리스탈은 10°(보석 파세팅) 등.
2. **고해상도 투명 렌더** — 512² 투명 배경, 3D 씬과 같은 조명 구성.
3. **게임 아트 마감** (`E:\workspace\claude\neon-fleet-art\props2d\finalize_props.py`)
   3D 렌더는 사실적 PBR이라 어두운 우주 배경에서 밋밋합니다. 채도·밝기·대비 보정 + 실루엣 외곽 발광.
   발광색은 개체 성격을 따릅니다 — 보상(코인·파워·크리스탈)은 강하게, 위험물은 배경과 구분될 만큼만.
4. **배선** — `sprites.js`에 8종 등록(기존 ID 4개는 경로 교체, 신규 ID 4개 추가) + `PROP_` 선로딩 포함.
5. **draw 교체** — 코드 도형 5종을 스프라이트 blit으로. **상태 표시는 전부 남겼습니다.**

### 상태 표시를 남긴 방식

그림만 바꾸고 게임이 알려주던 정보를 잃으면 안 됩니다.

- **잔해** — 붉은 경고 맥동은 "파괴 불가, 피하라"는 유일한 신호입니다.
  처음엔 원형 후광으로 옮겼는데, 잔해가 세로로 긴 구조물이라 **원이 본체보다 커져 "빨간 공"으로 보였습니다**(실측).
  → **실루엣 그림자**(`shadowBlur`)로 바꿨습니다. 그림 모양을 그대로 따라가 경고는 살고 본체는 또렷합니다.
- **기뢰** — 무장 여부를 선 색으로 알리던 것을, 무장 시 붉은 후광으로 옮겼습니다(원형이라 원 후광이 잘 맞습니다).
  폭발 반경 예고 링·중앙 맥동 코어·변이 표시는 그대로.
- **돌격기** — 붉은 조준 예고선·경고 링·HP 바·변이 표시 그대로. 모델의 코가 이미 진행 방향(아래)을 향합니다.
- **파워업** — 맥동을 크기 변화로 남겼습니다. 옛 'POW' 글자는 뺐습니다 —
  모델 자체가 별 아이콘이고, 작게 그려지면 글자가 뭉개져 오히려 지저분했습니다.
- 스프라이트가 아직 로드되지 않았을 때를 위해 **옛 코드 도형은 폴백으로 전부 남겨** 두었습니다.

## 5. 적탄도 3겹으로 (이사 지시 "적탄도 코어+헤일로 2겹으로 개선해줘")

적탄은 3D에도 실모델이 없고 절차적 플라즈마로 그립니다. 그래서 그림을 가져오는 대신
**3D 플라즈마의 구조를 2D 코드로 옮겼습니다.**

3D 파트(`createEnemyBulletParts`)는 3겹입니다 — 흰 코어(0.22) / 진행축으로 1.35배 늘어난 셸(0.34) /
뒤쪽 원뿔 꼬리(반경 0.18·길이 0.55). 2D는 색 원 + 작은 흰 점뿐이었습니다.

| | 이전 | 이후 |
|---|---|---|
| 구조 | 색 원 + 흰 점(0.35r) | 꼬리 + 셸 + 백열 코어(0.42r) |
| 방향 | **알 수 없음** | 진행축으로 회전 — 어디로 날아가는지 보인다 |
| 색 | 불투명 | 불투명(유지) |

### 실측으로 두 번 고쳤습니다

1. **3D 비율을 그대로 쓰니 "올챙이"가 됐습니다.** 꼬리가 길고 셸이 판정 반경보다 컸습니다.
   2D는 판정 원(r)이 곧 플레이어가 읽는 크기이므로 꼬리 1.45→1.15, 셸 1.35→1.2로 조여
   r 안쪽에 머물게 했습니다.
2. **셸까지 가산합성으로 그렸더니 색이 탁해졌습니다.** 검은 배경 위 가산합성은 결과가
   `색 × 알파`가 되어 62% 밝기로 어두워집니다(실측 — 주황이 갈색으로 보였습니다).
   → 셸은 불투명으로 원래 색을 온전히 내고, **꼬리만** 가산합성으로 은은하게 깝니다.

적탄은 화면에 수십 개가 동시에 뜨므로 `shadowBlur`는 쓰지 않았습니다 — 타원 2개 + 원 1개뿐입니다.

바늘·고리·잉걸 탄은 각자 다른 정체성(참격·깃털·용암)이 있어 그대로 뒀습니다.
