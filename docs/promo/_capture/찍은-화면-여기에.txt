찍는 법 (윈도우 기본 기능, 설치 불필요)
  스크린샷 : Win + Shift + S  → 영역 선택 → 자동 복사 → 그림판 등에 붙여 저장
  화면 녹화 : Win + G (게임 바) → 녹화 버튼 → 영상은 Videos\Captures 에 저장

찍어 주시면 좋은 장면 5가지
  1. 3D 함미모드 — 기함 뒤에서 적이 몰려오는 장면 (200% 이상 확대 시 전환)
  2. 보스전 — 보스와 탄막이 같이 보이는 순간
  3. 차지 랜스 발사 — 화면을 관통하는 빔
  4. 편대가 크게 불어난 상태 — 드론이 많을수록 좋다
  5. 워프 게이트 통과 직전 — ×2 / ÷2 갈림길이 보이는 순간
