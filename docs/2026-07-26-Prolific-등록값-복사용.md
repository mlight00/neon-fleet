## 5. 완료(Completion) 설정 — 소유자 입력 위치

Prolific은 "How to record a completion"에서 **Redirect(완료 URL)** 또는 **Completion code** 중 하나를 준다. 어느 쪽이든 아래 위치에 반영한다.

### 5.1 성공 완료 URL (Redirect 방식)

- Prolific이 제공하는 completion URL을 복사.
- 코드 반영 위치: `js/playtest-config.js`

```js
export const PROLIFIC_COMPLETION_URL = '';    // ← 여기에 Prolific 성공 완료 URL 붙여넣기
```

- 채우면: 설문 제출 후 최대 500ms 전송 창을 거쳐 이 URL로 이동(`completion_method=redirect`).
- 비우면: 이동 없이 `Test complete — return to Prolific and enter the completion code shown in the study.` 안내(`completion_method=manual`).

### 5.2 no-consent 반환 URL (선택)

- 동의 거부 참가자를 되돌릴 Prolific 반환 URL이 있으면 복사.
- 코드 반영 위치: `js/playtest-config.js`

```js
export const PROLIFIC_NO_CONSENT_URL = '';    // ← (선택) 동의 거부 시 반환 URL
```

- 비우면: 거부 시 이동 없이 영어 안내만 표시(안전).

### 5.3 GA4 measurement ID (측정하려면 필수, 아니면 비워도 게임 정상)

- NEON FLEET 전용 GA4 웹 스트림의 `G-XXXXXXX`.
- 코드 반영 위치: `js/analytics-config.js`

```js
export const ANALYTICS_CONFIG = Object.freeze({
  enabled: false,          // ← 측정 시작 시 true
  measurementId: '',       // ← 유효한 G-XXXXXXX
  // ...
});
```

- 비우거나 `enabled:false`면: 동의 UI 미표시·외부 스크립트 미로드·네트워크 0(게임·설문·완료 흐름은 정상).
