## 상태 정의

- **완료** = 구현 + 자동검사(잠그는 테스트 있음) + 브라우저 실기 확인(verify-report의 Playwright 스모크, 또는 이 세션의 실기 확인 7건: ① S1·S2·S3 무조작 완주 ② 게이트 −3→+6 색 전환 ③ 분리벽 좌 통로 스냅·대형 압축 ④ 연속 증원 발판 15칸 ⑤ 중화기 65명 탄막 ⑥ 결과 화면·다음 작전·스테이지 선택 ⑦ 키 조향 정상).
- **자동검사** = 테스트로 잠겨 있으나 실기(브라우저 육안) 확인 근거가 없음.
- **구현** = 코드는 있으나 전용 자동검사·실기 확인 근거가 모두 없음.
- **예정** = 1단계 범위 밖(아레나·영웅·기지·드론·보너스전·3칸 게이트·원근 투영·차량·구출 등, DESIGN 0장 명시).
- **대상아님** = 02 문서 자체가 "원작 UI 관찰만 있음"이라 표기한 항목(V53·V54). 완료로 처리하지 않는다.

근거가 애매하면 한 단계 낮춰 표기했다. "이 세션 실기확인"은 사용자가 이번 요청에서 명시한 7개 항목에 한정하며, 그 밖의 항목에 대해 완주가 곧 해당 항목의 육안 확인을 뜻한다고 추정하지 않았다(예: 병력 손실 장면·통 내용물 표시·정예 경고 배너는 완주와 별개로 미확인 처리).

## (1) 이번 버전에서 사용자가 실제로 할 수 있게 된 행동

1. 타이틀 화면에서 스테이지를 선택해 순수 전투에 출격한다.
2. 좌우로 부대를 조종한다(마우스 호버 절대 위치, 터치 드래그 상대 이동, 좌우 화살표/A·D 키).
3. 부대가 자동으로 전방 사격한다 — 병사마다 자기 위치에서 탄이 나가 한 점에 모이지 않는다.
4. 사격으로 게이트 칸의 부호 숫자를 올려 음수를 양수로 바꾸고, 통과 시 양수면 병력이 늘고 음수면 병력을 잃는다.
5. 병사 통·무기 통을 사격으로 파괴해 병사를 합류시키거나 무기(기관총/중화기)로 교체한다. 약한 무기 통은 무시된다.
6. 연속 증원 장치(파란 컨테이너)를 사격해 발판을 늘리고, 발판을 밟아 병사를 계속 합류시킨다(최대 15칸).
7. 중앙 분리벽 구간에서 대형이 자동으로 좌/우 한쪽 통로에 붙고 폭에 맞게 압축된다.
8. 추격형(grunt)·돌진형(rusher)·저격형(shooter) 적의 웨이브를 뚫고 지나간다.
9. 스테이지 끝의 정예(보스)와 싸워 격파하면 즉시 승리한다. S3 정예는 4초마다 잡졸 2를 추가로 소환한다.
10. 결과 화면에서 성공/실패, 생존 병력, 최고 기록, 걸린 시간, 처치 수, 신기록 여부를 확인하고 [다시 도전]·[다음 작전]·[스테이지 선택]으로 이동한다.
11. ESC/일시정지 버튼으로 멈추고, 탭 전환이나 창 이탈 시 자동으로 일시정지된다.
12. 진행 기록(클리어 여부·시도 횟수·최고 생존·최고 시간)이 저장되어 다음 방문 때 이어진다.
