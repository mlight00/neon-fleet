## 2. "추가 탄은 적·보급 통에만, 게이트에서는 사라짐"을 넣을 때 필요한 표시와 갈라질 줄(구현하지 않음)

1. **탄의 표시:** 추가 탄에만 `gateHit: 0`(규칙용)과 `extra: true` 같은 표시(그림·이벤트용)를 싣습니다. 메인 로봇의 원래 탄 1발은 `gateHit: 1` 그대로 둬야 합니다. `ownerId`만으로는 원래 탄과 추가 탄을 가를 수 없습니다.
2. **만드는 곳:** `combat.js` `fireUnits` L323-336. 메인 로봇일 때만 추가 탄을 더 넣는 분기가 도로(L332)와 광장 조준(L329) **두 곳 모두**에 필요합니다. 메인 로봇을 알아볼 표시는 지금 없으므로 `createRun` L128 에서 붙여야 합니다(3번 담당 항목과 겹침).
3. **이벤트:** `gates.js` L90-92 는 증가량이 0 이어도 `gateHit` 이벤트를 냅니다. 셸 `main.js` L714-723 은 이 이벤트에 흰 플래시와 숫자음(`gateTick`)을 냅니다. 그대로 두면 **수치가 오르지 않는데 오르는 것처럼 보이고 들립니다.** 증가량 0 일 때 다른 이벤트를 내거나 이벤트에 증가량을 싣는 분기가 필요합니다.
4. **닫힌 셔터(L82-85):** 추가 탄도 흡수되어 `gateBlock` 이 납니다. 기존 탄과 같아서 충돌이 없습니다.
5. **확정 칸(gates.js L68-70, combat.js L386):** 확정 칸은 충돌 후보에서 빠지므로 **추가 탄도 사라지지 않고 통과해 뒤의 적·통에 맞습니다.** 검토자가 걱정한 "뒤쪽 보급 통을 뜻밖에 관통"은 지금도 확정 칸에서 **모든 탄**에 일어나는 r3.30 규칙입니다. 추가 탄만 확정 칸에서 막으려면 L386 에 추가 탄 예외를 넣어야 하는데, 그러면 추가 탄이 보통 탄보다 불리해집니다. 확정 칸 통과는 그대로 두는 편이 일관됩니다.
6. **증원 설비 발판(supply.js L184-191):** 검토자 안대로 "보급 통에는 효과"를 주면 추가 탄 1발이 발판 1개를 더 만듭니다. 게이트와 같은 '1발당 +1' 복리 경로이므로 **게이트와 같은 규칙을 적용할지 따로 정해야 합니다**(3번 스테이지 c4 증원 설비, 최대 15).
7. **봇 도구:** `rush3-policies.mjs` L110-115 `expectedGateHits` 는 `병력 × 부채꼴 발 수`로 게이트 명중을 어림합니다. 메인 로봇 다연발이 생기면 이 어림도 고쳐야 봇의 칸 선택이 맞습니다(규칙 결함은 아님).

- 부대 전체 화력 증가율((E − 1) ÷ n)로 보면, 화력 1은 n 25 에서 +1.2%, n 70 에서 +0.4%입니다. 검토자의 "30명이면 +1%"는 산수로 맞습니다. 다연발 1은 n 25 에서 +4.0%, n 70 에서 +1.4%입니다.

- **판마다 병력 폭이 매우 큽니다.** 1·2번은 STEP 의 15~76%(1번), 37~47%(2번) 동안 병력이 5명 이하였고, 3번 evLead 는 66% 동안 30명 이상이었습니다. 2번은 보스 등장 때 13명이던 부대가 보스전 동안 중앙값 2명까지 줄어 세 봇 모두 졌습니다. 메인 로봇 강화가 가장 크게 보이는 곳은 **1·2번 초반과 2번 보스전**이고, 3번 후반(70명)에서는 1~3%에 그칩니다.

## 7. 게이트 포화 기준선(강화 0단계, 봇 결과)

셔터는 부대 앞 340px 에서 열리므로 열림부터 통과까지 약 1.8초입니다(측정 1.80초). "상한 도달"은 칸 값이 `maxValue` 에 닿은 첫 STEP 입니다. evLead 기준, 괄호는 다른 봇.

- 강화 0단계에서도 evLead 가 고른 칸은 5개 중 4개가 통과 전에 상한에 닿습니다. 상한에 닿은 뒤의 탄은 확정 칸 규칙으로 통과합니다.
- **상한에 못 닿거나 여유가 작은 칸**이 게이트에 들어가는 강화가 영향을 주는 곳입니다: 1번 첫 게이트(병력 1명 = 메인 로봇 혼자 쏨), 2번 g2 우 칸(소총 6명으로 −20→+6), 3번 g1 우 칸(여유 0.27~0.40초).
- **추정(규칙 계산 아님):** 메인 로봇 탄이 칸 명중의 1/n 을 차지한다고 보면, 다연발 1의 추가 탄이 게이트에도 +1 일 때 1번 첫 게이트는 명중 약 10 → 20(값 11 → 상한 15, **병사 +4**), 2번 g2 우 칸은 +6 → 약 +10, 3번 g1 우 칸은 명중 65 에 약 +2.6(상한 도달이 약 4% 빨라짐)입니다. 검토자 안(추가 탄은 게이트 무효)이면 이 효과는 모두 0 이 됩니다. 반대로 말하면 **1번 첫 게이트는 메인 로봇만 쏘는 구간이라, 다연발을 게이트에 넣으면 첫 구매 효과가 가장 크게 보이는 곳**이기도 합니다. 연사 1이 게이트에 들어가면 1번 첫 게이트 명중은 약 11~12(값 12~13)입니다.
