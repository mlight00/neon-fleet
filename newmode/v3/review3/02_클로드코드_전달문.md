# Claude Code 전달용 — v4 기획 수정 의견

첨부 `01_GPT_v4_기획검토.md`를 바탕으로 v4 기획을 수정할 때 참고할 내용입니다. 현재 사용자는 기획 파일을 전달했고, 이 검토에서는 구현·커밋·배포를 수행하지 않았습니다. 아래는 후속 기획 제안이며 실행 승인을 대신하지 않습니다.

## 유지할 방향

- 확대 보기 기본 고정, 사용자 난이도 선택 제거.
- 코인 누적과 메인 로봇 전용 영구 강화. 일반 병사 강화 금지.
- run 생성 때 강화 상태 전달, 순수 전투 코드와 저장 분리.
- 판 안 Mk 유지, 무기 공통 영구 강화, 옛 rush 코인 미이관.
- 소환 적·접촉 소멸·개발용 판 0코인, 패배·중도 포기 처치 수입 유지.

## 확정 전에 고칠 사항

1. 첫 화력 구매 1→1.3은 체력 4 적의 처치 탄 수가 4발 그대로다. 첫 구매는 다연발 등 눈에 보이는 효과를 먼저 시험하고, 가격은 첫 1~2회 실제 수입으로 정한다.
2. 영구 추가 탄의 게이트 효과를 별도 검증한다. 시제품 비교안: 기존 탄 +1, 추가 탄은 게이트 수치를 올리지 않고 닿으면 소멸. 적과 보급 통에는 적용. 연사는 우선 게이트에도 적용. 설명과 탄 모양을 함께 구분한다.
3. hero 표시는 유지하되 게이트 감소량 ≥ 전체 병력이면 패배한다. hero를 마지막 제거 대상으로 두는 것과 전멸 면제를 구분한다. 적 피해를 호위 병사에게 이전하려면 대상 선정·범위 피해 중복 방지·보호막 표시를 명시한다.
4. 현 코드 모든 스테이지 자유 진입과 중도 포기 지급의 조합을 경제 위험으로 추가한다. 신규 순차 해금/기존 진척 이관/무보상 연습을 검토한다. 일반 적 보상은 HP와 분리한 스테이지 예산 방식을 우선 비교한다.
5. 코인 21,031은 이론 상한이지 실제 수입이 아니다. 3,830 비용과 두 바퀴 목표를 고정하지 않는다. 정상 도전·쉬운 판 반복·후반 일부 처치 후 포기의 수입/분을 비교한다. 강화 이후 수입도 재측정한다.
6. T1은 S2를 제외하지 말고 초반 곡선을 조정한다. T2는 '강화 없이는 클리어 불가' 대신 '강화로 재도전 횟수와 보스전 시간이 유의미하게 개선'으로 바꾼다. HP 일괄 상향으로 숙련자의 무강화 승리를 막지 않는다.
7. 강화 6개 혼합 묶음 외에 동일 소비 코인 기준 화력·연사·다연발 우선 경로를 비교한다. 직격만 강화하면 '직격 화력'으로 표기하거나, 로봇 탄의 폭발·연쇄 피해까지 포함하도록 별도 검증한다. 기절 시간 배증은 제외한다.
8. 저장 v:3 유지와 기록 규칙 구분은 별개다. v4 기록 칸을 만들고 이전 brutal 기록은 과거 기록으로 보존한다. 최고 생존과 최단 시간마다 각각 강화 3트랙 스냅샷을 저장한다.
9. commitMain / finishRun / 보너스 / 포기 사이의 코인 중복 정산을 막는다. 지급 식별자·지갑을 함께 저장하고 구매 잔액과 단계도 함께 저장한다. 연타·새로고침·저장 실패·복수 탭 정책을 검사한다.
10. 사람 관찰을 마지막으로 미루지 않는다. 1~3번 '전투→코인→구매→재도전' 시제품을 먼저 검토한다. 24판 확장과 최종 가격 확정은 그 뒤다.
