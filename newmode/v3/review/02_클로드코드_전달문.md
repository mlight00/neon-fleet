# Claude Code 후속 작업용 전달문

이 문서는 사용자가 후속 구현을 지시할 때 함께 전달할 초안이다. 현재 검수 작업에서 수정·배포를 실행한 것은 아니다.

`01_GPT_1단계_검수결과.md`를 먼저 읽고, 현재 작업 브랜치 상태를 확인한 뒤 아래 범위의 수정안을 진행해 주세요. 기존 게임과 별도인 rush3 흐름을 유지하고 배포하지 마세요.

1. 마우스→키보드 전환 시 방향키가 7px 정도에 묶이는 오류를 고쳐 주세요. 원인은 combat의 STEP마다 pointerX를 다시 대입하는 것과 input에 남아 있는 마우스 목표입니다. 키 해제 후 과거 마우스 위치로 복귀하지 않고, 마우스 재이동 시 자연스럽게 전환되도록 하세요.
2. S2 양쪽 통 동시 획득 재현을 고쳐 주세요. 현재는 왼쪽 통을 z1659.3에서 얻고 오른쪽 통로로 들어가 z1960.2에서 무기까지 얻습니다. 분리벽의 필수 선택 구간에서는 한쪽만 얻도록 배치·노출 시간을 바꾸세요. 통을 z2500~2600으로 옮기는 것은 실험 출발값이지 확정 사양이 아닙니다.
3. S3 오른쪽 고정으로 64명이 생존하고 59.5초에 끝나는 경로를 보완해 주세요. 적극 조준 결과는 70명/59.2초입니다. 병사·연속증원·무기·위협을 배치해 최소 두 번의 의미 있는 선택 기회를 만들고, 큰 성장 보상은 남겨 주세요. 단순 적HP 상향 또는 병력 비례 숨은 감쇠로 해결하지 마세요.
4. 통·적 충돌 우선순위를 원의 최전방 z가 아닌 실제 최초 교차점으로 정렬하세요. probe.mjs의 nearest 재현 상황에서 앞의 적이 먼저 맞아야 합니다.
5. 변경한 배치의 버전과 최고 기록 처리 방침을 명시하고 기존 저장을 임의 삭제하지 마세요.

게이트는 기본 1발=+1을 유지하고, 전투 전체 사거리보다 게이트 자체의 노출·사선·선택 시간을 먼저 조절하세요. 구체적 실험안과 다섯 질문 답변은 검수결과 문서를 따르세요. 새로운 아레나·기지 확장은 이번 보완 뒤 별도로 검토하세요.

검증은 기존117개 검사+독립 재현 검사+3스테이지×7입력 정책을 다시 실행하고 전후 표를 작성하세요. probe.mjs는 게임 원본 수정 없이 동일 stepRun을 사용하는 진단 스크립트이며, 수정본 경로에 맞게 import만 조정해 사용할 수 있습니다. 정책별 성공률을 실제 사람의 성공률로 표현하지 마세요. 스마트폰 실기는 기종·가독성·터치/회전/중단복귀·후반 병력 성능을 기록하고 미실시 항목은 명시하세요.
