# 수정 라운드 1(2026-09-17) — 확정 −10 게이트의 열림 안내

지적 = 2차 검수 후속 [major] "셔터가 열릴 때 띄우는 '지금 쏘면 +1' 안내가 행 종류를 보지 않고 무조건 붙는다".
반영 계약서 = `newmode/v3/DESIGN_v3_stage1.md` **r3.6 수정 라운드 1**(§3-2 · §6 · §8).

## R1-0. 한 줄 요약

**쏴도 값이 오르지 않는 행에 '지금 쏘면 +1' 을 약속하지 않게 고쳤다.** 그 행(랜덤 길 ⑤ 확정 −10 게이트)에는 대신
**'쏴도 그대로예요'** 가 뜬다 — 이미 칸 아래 붙어 있는 **'확정' 꼬리표와 같은 말**이라 서로를 보강한다.
**규칙 STEP·배치 좌표·난이도 배수·랜덤 풀·효과음은 한 줄도 바뀌지 않았다.** 바뀐 것은 셸이 고르는 **문구 하나**다.

## R1-1. 무엇이 문제였나

- `main.js` 의 `gateArm` 처리는 행을 보지 않고 언제나 `GATE_TIP_OPEN`('지금 쏘면 +1')을 넣었다.
- 그런데 값이 오르는 공식은 `gates.js` 의 `cell.value = min(cell.maxValue, cell.value + gain)` 이다.
  랜덤 길 ⑤ `trapGate` 는 **값 −10 · 상한 −10** 이라 몇 발을 맞아도 −10 그대로다(`gateHit` 이벤트·플래시·`gateTick` 소리는 그대로 난다).
- 그래서 **한 화면에 '확정' 과 '지금 쏘면 +1' 이 같이 떠 서로를 부정**했다. N2 가 없애려던
  "맞고 있는데 왜 숫자가 안 변하지?" 를 바로 그 행에서 새로 만들던 셈이다.
- 게다가 벽 `w3` 우측 통로를 탄 판에서는 **피할 수도 없다** — 통로 x ≥ 265 이고 게이트 칸이 [252,400) 이라 반드시 그 칸에 걸린다.

판정은 한 곳에만 둔다.

```js
export function isFixedGateRow(row) {
  const cells = row && Array.isArray(row.cells) ? row.cells : null;
  if (!cells || cells.length === 0) return false;
  return cells.every((c) => c.value < 0 && c.maxValue != null && c.maxValue <= c.value);
}
```

**`render.js` 의 '확정' 꼬리표와 같은 조건**이다 — 그래서 꼬리표가 붙는 행에서만 새 문구가 뜬다(두 표시가 어긋날 수 없다).
닫힘 문구 "가까워지면 열림" 은 확정 행에서도 참이므로 그대로 둔다(열리기는 한다 — 오르지 않을 뿐이다).

## R1-3. 영향 범위 — 이 문구가 바뀌는 행은 하나뿐

세 스테이지 × 세 난이도의 **코스 게이트 전부를 훑어 확정 행이 하나도 없음**을 확인했다(실행 출력: 해당 행 0줄).
확정 행은 **랜덤 길 ⑤ `trapGate` 하나**이고, 세 난이도에서 모두 같은 값이다.

```
normal g2 [[-10,-10]] fixed=true
hard   g2 [[-10,-10]] fixed=true
brutal g2 [[-10,-10]] fixed=true
```

**이사 결정 대기 3건은 그대로다** — 기본 난이도(극한)·재도전 시드 정책(판마다 새 시드)·**확정 −10 게이트의 존폐와 외형**.
이번에 바꾼 것은 그 게이트를 **없애거나 모양을 고친 것이 아니라**, 열릴 때 띄우던 **틀린 안내 한 줄**이다.
