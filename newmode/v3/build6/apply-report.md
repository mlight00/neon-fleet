확정선 전에도 **게이트 두 종은 `gateClang` 을 내고 보급 통 3종은 무음**(`supplyBlock`)이다. 그래서 **'게이트냐 통이냐'는 여전히 소리로 샌다.** 이번 커밋이 만든 문제가 아니고(종전부터 그랬다) 이사 결정·지적 범위 밖이라 손대지 않았으며, §3-9 에 **미해결로 명시**해 두었다. 막으려면 공개 전 `gateBlock` 을 `supplyBlock` 처럼 무음·무연출로 두는 방법이 있는데, 그러면 "탄이 왜 안 나가지?"가 설명 없이 남는다 — 저울이 달라지는 결정이라 따로 여쭙는 편이 맞다고 본다.

그 밖에 6장의 남은 항목(극한 S2 성공 경로 봇 미입증 · 미채택 권고 2건 · 스마트폰 실기·초보 관찰 미수행)은 그대로다.

# 8. 수정 라운드 2 — 계약서가 지킨다고 적은 소리를 검사가 실제로는 안 보고 있었다 (2026-09-17)

지적 1건(major) 반영. **커밋·푸시·배포 없음** · 기존 `rush/*`·`rush.html`·`tests/rush-*` 무수정 · **규칙·표현 코드 무변경**(이번 라운드는 검사 1줄 + 문서).

## 8-1. 지적이 맞다 — 변이 실험으로 직접 재현했다

계약서 §8 은 "`SFX_NAMES3` 에 `gateOpen`·`gateClang`·`lotWarn`(r3.7 `trapHit` 추가) 이 있고" 라고 적어 두었는데, 실제 검사(`tests/rush3-save.test.mjs` `V3-AUDIO`)의 `need` 배열은 `'gateOpen', 'gateClang', 'lotWarn'` 에서 끝나 있었다. **결정 ③ 의 유일한 구별 소리가 무방비였다.**

| 실험 | 실행 명령 | 결과(실제 출력) |
|---|---|---|
| 기준선 | `node --test tests/rush3-*.test.mjs` | `tests 241 · pass 241 · fail 0` |
| **변이(고치기 전)** — `rush3/audio.js` 의 `trapHit: ['nf_sfx_hit_1','nf_sfx_hit_2'],` 한 줄 삭제 | 같은 명령 | **`tests 241 · pass 241 · fail 0`** — 전건 통과 |
| **변이(고친 뒤)** — 같은 한 줄 삭제 | 같은 명령 | **`tests 241 · pass 240 · fail 1`** — 떨어지는 것은 `V3-AUDIO` 하나 |

(변이는 `sed` 로 넣었다가 백업본으로 되돌렸다. 현재 `rush3/audio.js` 는 라운드 1 끝 상태 그대로다 — `trapHit` 3곳 유지.)

## 8-2. 왜 다른 검사가 못 잡나 (두 갈래 다 확인함)

- **파일 존재 검사**(`tests/rush3-save.test.mjs` 아래쪽, "SFX 맵의 모든 이름이 실존 음원 파일로 간다")는 `for (const name of SFX_NAMES3)` 로 **맵 자신을 순회**한다. 이름이 맵에서 사라지면 검사 대상에서도 함께 사라진다 — 빠진 것을 빠졌다고 말해 줄 수 없는 구조다.
- **셸 검사**(`tests/rush3-loop.test.mjs`)의 가짜 오디오는 `sfx(n, o) { played.push([n, o?.vol]); return true; }` 다. **모르는 이름도 무조건 `true`** 이므로, `V3-SHELL-TRAP` 이 "`trapHit` 이 울렸다"고 확인해도 그 이름이 실제 음원으로 이어지는지는 보지 않는다.

즉 **이름 목록(`need`)이 이 소리들의 유일한 안전망**이었고, 거기에 `trapHit` 만 빠져 있었다. 실제 결과는 "브라우저에서 함정 게이트가 소리 없이 조용해져도 검사는 전부 초록" — `V3-AUDIO` 를 만든 이유("없는 파일을 매핑하면 소리가 조용히 사라진다 — 브라우저에서만 드러난다")와 **정확히 같은 실패 모드가 이번에 추가한 소리에만 열려 있었다.**

## 8-3. 고친 것

| 파일 | 바꾼 것 |
|---|---|
| `tests/rush3-save.test.mjs` | `V3-AUDIO` 의 `need` 배열에 **`'trapHit'` 추가**(+ 왜 여기서만 잡히는지 한 줄 주석). 단언 약화 없음 — 지키는 이름이 하나 늘었을 뿐 |
| `newmode/v3/DESIGN_v3_stage1.md` | 머리말 r3.7 항에 **수정 라운드 2** 문단 / §8 `V3-AUDIO` 를 다시 씀 — `trapHit` 을 괄호 밖 본문으로 올리고, **"이름 목록은 이 소리들의 유일한 안전망"**(다른 두 검사가 왜 못 잡는지)과 **"새 소리를 추가할 때는 반드시 `need` 목록에도 적는다"** 를 규칙으로 명시 |

`rush3/*` 는 이번 라운드에 **한 글자도 바꾸지 않았다.**
